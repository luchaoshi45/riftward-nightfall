# 余烬守望 · Riftward Nightfall

Godot 4.7.2 与 Blender 4.5 制作的原创单机末日守夜原型。主场景已从三路 MOBA 切换为据点防守与外围搜集。旧版工程文件留作历史素材，不在当前游戏入口运行。

## 开始游戏

协作开发只需阅读唯一协作文件 [AGENTS.md](AGENTS.md)，其中包含项目规则、派工与交接。每台电脑一个主对话，仓库只保留 `main` 一个分支，两台都拉取、提交并推送 `main`；文件更新后必须同步GitHub，不再创建功能分支或PR。本仓库包含代码、运行素材、Blender源文件、生成脚本和测试，二进制资源使用Git LFS。

克隆前安装Git LFS，克隆后运行 `git lfs pull`。安装[Godot4.7.2稳定版](https://godotengine.org/download/windows/)，双击 `打开编辑器.cmd`，等待资源导入后按F5。入口会核对版本；默认查找Program Files/Godot、用户LocalAppData/Godot、项目.tools/godot和PATH，也可把 `GODOT_EXECUTABLE` 环境变量设为新版console.exe的完整路径。运行现有模型不需要Blender；修改美术源时使用Blender4.5。新克隆没有本地 `build/`，请从Godot运行或安装4.7.2导出模板后自行导出Windows版本。

最新已验证Windows版本为0.8.24，完成34/100，以 [optimization-progress.json](optimization-progress.json) 为准。日间随机委托与返家交付：真实采集、能源、救援、封巢进度，P指路与早返奖励。

后续策划目标为多轮短局合计约一小时、每局重新构筑，并逐步增加防御兵种、怪物与局内主城扩建；详细方案见 [DESIGN.md](DESIGN.md)。当前仍是三夜原型，标准四夜局、小队、城区和局间解锁尚未实现。

开发及本版成品使用4.7.2，已通过核心玩法、实际Vulkan画面及Windows导出启动/关闭检查。`打开编辑器.cmd` 使用新版；已有4.6.2编辑器窗口需由用户方便时关闭再重开。`启动游戏.cmd` 已指向0.8.24；旧 `build/Riftward_Nightfall_engine4.7.2_check.exe` 只保留作之前的引擎兼容验证包。

编辑器入口会核对当前项目的已开窗口：版本不符时要求先保存并关闭旧编辑器，同为4.7.2时复用已开窗口。`.glb.import` 是需要共享的模型导入配置；若旧编辑器删除了新版的三项默认值，可先运行 `python tools/repair_godot_import_rewrites.py` 只读检查，关闭本项目所有编辑器后加 `--apply` 备份并恢复。工具只处理与已提交版本精确匹配的旧版回写，保留其他手动或暂存的修改；不可用忽略配置文件的方法掩盖问题。

本机有成品时双击 `启动游戏.cmd` 或 `build/Riftward_Nightfall_v0.8.24.exe`。游戏从黑夜中的余烬哨站开始：选择一张命运卡后立即守卫南门，开局提供两座守门塔、90 零件和一发火焰机关。每夜持续105秒；次日白昼只有90秒，趁亮外出搜集、回收能源芯和救援哨兵，再回防中央灯塔。熬过三夜即完成当前原型的一局。守望者倒下或灯塔被毁则失败。

素材来源见 [ASSETS.md](ASSETS.md)，许可说明见 [LICENSES.md](LICENSES.md)。两台按AGENTS分配的文件范围工作，提交和推送前同步最新 `main`，保留其他协作者的改动；远端已前进时先正常合并，禁止强推覆盖。

## 当前可玩内容

- 一座可探索的废墟哨站：中央灯塔、三面封闭栅栏与南门、放射状旧路、断壁、枯树、废料箱和灰烬地表。
- 白天搜集废料箱、封闭夜巢、修复通信塔，并参与发电机守圈与哨兵护送；夜晚南门集群来袭，灯塔自动脉冲防御。
- 36 处废料箱采完 55 秒后刷新；新增 18 处荧光互动点，采完 45–65 秒后改变地点及种类。余烬花奖励 12 零件、恢复 70 生命；记忆晶簇奖励 12 记忆、恢复 45 法力；补给箱留守三秒开启，奖励 40 零件和 6 记忆，离开四米会中断；引路灯碑点亮后提供 30 秒照明和七米护盾灯区，燃尽后 50 秒刷新。
- 每完成五次采集或中立互动，额外奖励 35 零件及 20 记忆；浮字、拾取音效、光环和 HUD 显示奖励。每累计 100 记忆可选择一张属性强化卡；选卡及暂停时刷新计时停止。
- 每局四只随机中立生物在外围漫游，互动后 60 秒换地点刷新。荧角鹿给予 90 护盾、恢复 60 生命及 6 记忆；苔背甲虫用 20 零件交换 80 法力、40 生命及 8 记忆。它们不参与敌人战斗，R 不会伤害它们。
- 三处废墟发电机：F 启动后在灯圈内充能 12 秒，同时清除三只追击潜伏体；离圈暂停充能。每台奖励 100 零件和一枚能源芯，灯塔脉冲间隔永久减少 0.2 秒，最低 2.5 秒。
- 两处哨兵营地：沈禾、周砚在 F 救援后跟随玩家绕障回家并触发伏击。真实抵达据点后本人留守、身旁增加一盏局部暖灯，每人奖励 80 零件、灯塔恢复 120 耐久、玩家恢复 100 生命；之后主动修灯节省 3 零件。未完成的远征日落时撤回，次日可重试；结算回应真实0/1/2人，不虚构哨兵死亡。
- 靠近废料箱按 F 获得 35 或 60 零件；受损灯塔附近按 F 消耗 20 零件修复 150 耐久，救援两名哨兵后降至 14 零件。击败怪物也获得零件与战斗记忆。
- 保留无装备的局内三选一卡牌强化。开局、每夜幸存与积满 100 战斗记忆可选卡；卡牌能力已接入新战斗。
- 守望者的自动近距普攻，以及斩光、屏障、突进、灯焰与治疗五项技能。
- 五个技能都有真实局部3D照明：Q/E光源沿方向运动，W/X随角色移动，R暖色爆发投影。光照照到地面与模型，随寿命消退，最多六灯及一盏阴影；暂停选卡冻结，F2减弱照明，原伤害和费用保留。
- 普攻先挥剑再命中，剑气短弧随目标传播；连续三段左右挥砍，第三段“破势”伤害提高 30%。命中、暴击、重击与击杀有独立浮字、碎光、短促姿势停顿及原创音效，镜头保持方向。2.8 秒没有命中则重置三段进度。
- 亲自普攻及其连锁击杀在六秒内延续连斩；3 / 6 / 10 连斩额外获得 5 / 8 / 12 零件和 4 / 6 / 10 记忆。塔防及技能击杀仍获原有收益，不增加普攻连斩。选卡、暂停时连击计时停止，昼夜转换重新起算。
- 四类夜行体被击败后保留真实模型与材质，折起四肢、倒地并化为飘散灰烬；噬灯蛾从悬浮高度坠落。尸体立即退出战斗，落地随坡道高度处理，最多保留12具，暂停与选卡冻结动画。
- 庭院、南门坡道和挡土墙使用石质颗粒、烟灰斑、裂纹与雨痕材质；保留现有接入。旧首次材质A/B切换卡顿未宣告解决，从机VIS-001仍负责复测与修复。
- 白昼探索、黑夜警戒与守城战斗配乐随局势切换，渐入渐出并保留六秒战斗余韵。选卡降低音量，暂停停播，拾取奖励时短暂降低配乐以突出反馈。配乐本地播放，无需联网。

## 操作

守望者基础移速为每秒 8.4 单位。键盘松手后立即停步，右键指令可接管移动；镜头固定方向并跟随位置。跑步节奏随实际速度变化，落脚、膝盖回收、肩胯反向摆动及衣摆跟随共同表达行动。

| 按键 | 功能 |
| --- | --- |
| ZASD / 方向键 | 移动（Z 或 ↑ 向上） |
| 右键 | 向点击位置移动，绕开堡垒栅栏，经南门回家 |
| Q / W / E / R / X | 斩光 / 屏障 / 突进 / 灯焰（第一天可用，85 法力、28 秒冷却） / 治疗 |
| F | 搜集、建塔/升级、修灯；启动发电机或救援哨兵 |
| H | 靠近受损防御塔，消耗 20 零件修复 100 耐久 |
| G | 靠近已建防御塔时切换“最近目标 / 破城优先”；破城体不在射程内时仍攻击最近目标 |
| C | 准星对准敌人后命令射程内防御塔集火 8 秒，冷却 22 秒 |
| B | 靠近南门时消耗 65 零件部署临时路障，承受 520 伤害并拖住正门夜行体；黎明自动收起 |
| T | 靠近南门时消耗 45 零件装填一发火焰机关，最多储存 3 发；夜行体踏上门前坡道时自动引爆 |
| 1 / 2 / 3，或点击卡牌 | 选择命运卡；选卡时 F 重抽（每局三次） |
| 滚轮 / 空格 | 调整镜头 / 恢复默认缩放 |
| Esc / Enter | 暂停与继续 / 结算后重开 |
| M / [ / ] | 配乐开关 / 降低配乐音量 / 提高配乐音量；音量偏好会保存 |
| F1 | 配乐来源、署名与许可；战斗中查看时先暂停 |
| F2 | 开关减弱震动与闪光；保留命中数字、音效及全部战斗奖励 |

故事方向与参考边界见 `STORY.md`，当前玩法规则见 `DESIGN.md`，资产来源见 `ASSETS.md`。开局动机、招募/返家回应、同伴家灯与结算表达“把人带回灯下，他们也会帮助你守住家”；完整对话、人物支线与后续章节仍是设计稿。

## 开发与验证

在 Godot 中打开 `project.godot` 并按 F5。当前入口是 `scenes/nightfall.tscn`；主要脚本为 `scripts/nightfall.gd`、`nightfall_world.gd`、`nightfall_hud.gd`。Blender 新场景源文件位于 `art_source/outpost/`，可用 `art_source/create_outpost.py` 重新导出。

```powershell
godot --path . --script tests/nightfall_loop.gd
godot --headless --path . --export-release 'Windows Desktop' build/Riftward_Nightfall_v0.8.24.exe
```

这是“守夜”玩法切片，尚无永久存档、NPC 对话、完整章节、物理破坏或大型开放世界。建模与灯光为原创风格化游戏资产，不使用参考作品的人物、名称和场景资源。

## 0.5.0 扩展

地图约 252×220 游戏单位，可探索面积约为上版十倍。白昼 210 秒、夜晚 105 秒；增加可修复的通信塔残骸、运输车、外围废墟和小地图。修复通信塔可回收 85 零件。中央有八处基座：60 零件建塔，50 与 75 零件升级；防御塔自动攻击接近的怪物。夜行体现在由独立四肢和头部节点驱动奔跑、扑袭与受击。

据点现为高出荒原约 5 单位的防守平台，三面是陡崖与深色挡墙，南门外有独立长坡和坡道侧墙，北、东、西三面封闭，仅南门供出入。夜袭改为从南方集结的大群怪物，沿南门攻入。镜头保持固定朝向，只随玩家平移。


## 0.6.0 夜袭与画面

夜袭新增疾行体与破城体：前者快而脆，后者缓慢、耐久高且专冲灯塔。白天潜伏体入夜撤离，所有夜袭都从南门出现。外围通信塔每修复一座，自动防御塔获得额外射程与伤害；三级塔获得小范围溅射。堡垒陡崖加入岩层色差，南门设置两盏夜间哨灯，灯光会轻微摇曳。


## 0.7.0 夜巢远征

荒原新增三处夜巢。白天先击败巢穴守卫，靠近按 F 封闭夜巢，可获得 90 零件；每封闭一处，夜袭开场数量减少 2，后续波次间隔延长 0.45 秒。未清除的夜巢会保留到下一天，仍可继续远征。夜巢在小地图以红色标记。模型由 Blender 原创制作，包含暗色甲壳、骨质尖端与微光核心。


## 0.7.1 防御塔目标

靠近已建防御塔按 G，可在“最近目标”和“破城优先”之间切换。破城优先只在射程内存在破城体时生效，否则防御塔仍会攻击最近的敌人；小地图上的橙红塔点表示已启用破城优先。

## 0.7.2 南门火焰机关

守望者可以在唯一入口处装填火焰机关。每发消耗 45 零件，最多储存三发；入夜后夜行体进入南门坡道便会引爆，对周围敌群造成 190 点伤害。机关爆发后有短暂间隔，防止一群敌人瞬间耗尽全部装填。门前发光刻痕和右上角 HUD 显示剩余发数。

## 0.7.3 五波夜袭

每夜改为五波南门进攻。左上角显示当前波次与下一波倒计时；进攻前四秒，南门哨灯变红并闪烁，屏幕中央提示即将抵达的波次。封闭夜巢仍会减少开场敌人数，并延长波次间隔。

## 0.7.4 夜行体扑击动作

夜行体攻击前会短暂蓄势、压低身体并亮出地面危险环；疾行体蓄势更短，破城体更长。目标离开攻击范围时攻击取消，扑击命中时有独立的肢体动作与火花反馈。奔跑摆腿按怪物移动速度变化，不再所有种类使用相同节拍。

## 0.7.5 飘灰天气

哨站和外围废墟加入缓慢横向漂移的灰烬颗粒。飘灰围绕玩家视野移动，不只停留在出生点；白天较稀疏且偏尘土色，夜晚密度增加并偏冷色。颗粒使用低亮度细片，避免遮挡敌人和塔防提示。

## 0.7.6 塔群集火号令

将准星移到夜行体身上按 C，可命令射程内的防御塔优先集火该目标 8 秒，即使防御塔平时设置为最近目标或破城优先。金色光环标示目标；目标死亡、离场或时间结束后自动恢复原有塔模式。号令冷却 22 秒，右上角显示状态。

## 0.7.7 昼夜光照过渡

日落与天亮时，环境光、太阳、雾色、天空背景、灯塔和南门哨灯在约六秒内平滑过渡；飘灰的密度与冷暖色也随之渐变。夜袭波次和防守操作照常进行，玩家能从画面逐渐变暗判断夜幕来临。

## 0.7.8 夜巢封印遗迹

封闭夜巢后，红色巢体会收缩，原址升起低矮的石质封印遗迹并亮起冷色纹路；小地图上的标记由红色危险点变为青色已清理点。封印遗迹由 Blender 原创建模，保存独立可编辑源文件，游戏中使用 GLB。

## 0.7.9 灯塔受袭警报

灯塔被夜行体击中时，屏幕顶部显示最近数秒的累计损伤与回防提示，灯塔耐久面板和小地图中心同步闪红。警报持续约三秒后消退，即使玩家正在外围搜集，也能及时发现据点已被突破。

## 0.8.0 第三夜结局分歧

守住第三夜后，结局会根据夜巢清理进度变化。全部三处夜巢封闭可达成“第四次日出”，林舟从三夜回声中找到地下曙光阵列入口；若仍有夜巢，哨站虽然幸存，却只能先为下一次远征保留资源。结算界面显示封巢数量，并使用不同的灯塔光色与剧情收束。

## 0.8.1 蚀塔夜袭

夜袭新增专门破坏南门两侧防御塔的蚀塔体，绿色警示圈用于快速辨认。防御塔拥有耐久，受损过半时基座亮起红圈；靠近可查看剩余耐久，被摧毁后可以重新建造，升级会恢复耐久。玩家需要在守门、保塔与修灯塔之间分配火力和零件。


## 0.8.2 战地修塔

靠近受损的防御塔按 H，消耗 20 零件恢复 100 耐久。修复后塔座的受损警示圈会随耐久状态消退；按 F 升级仍会恢复到新等级的满耐久。守夜时可临场决定优先清除蚀塔体、抢修火力点，或留资源修复灯塔。

## 0.8.3 南门路障

南门控制区按 B 可部署一座临时路障，消耗 65 零件，拥有 520 耐久。正门夜行体会先攻击路障再继续冲向灯塔；路障受损后以红色地环提示，小地图持续显示耐久。黎明后路障自动收起，守望者仍可越过路障外出。

## 0.8.4 夜行体动作

夜行体的跑动加入前后腿错位与身体倾斜；扑击改为明显的后撤蓄力、前冲命中和短暂受击回弹，命中守望者时出现地面冲击。夜袭敌群的模型比例略微放大，疾行体、普通夜行体和破城体在战斗镜头里更易分辨。动作仍由 Godot 的独立节点驱动，不属于骨骼动画。

## 0.8.5 夜行体造型

夜行体替换为 Blender 原创的灰烬猎犬模型：拉长躯干、分层背甲、骨刺脊线、关节护甲、钩爪与更明确的发光眼。导出时按身体、头与四条腿分别合并同材质网格，保留动作枢轴；Godot 校正正面方向后，怪物会以头部朝向追击目标。近景与正常战斗镜头均已检查。

## 0.8.6 防御塔射击特效

防御塔发射的单层光线改为暖色外缘与亮芯叠加，炮口短闪，落点地环快速扩散；光束及落点在约四分之一秒内收束消失。仅调整视觉反馈，射程、伤害和目标选择保持原规则。

## 0.8.7 斩光剑弧

Q 斩光从单一直线改为两道收尖的青色剑弧，配合淡化的扇形范围提示。特效沿当前瞄准方向快速展开、旋转并消散；视觉扇区与原有伤害判定保持一致。

## 0.8.8 南门夜间照明

完整入夜后，两盏南门哨灯会向坡道外投射暖色照明，夜行体进入灯区时可提前辨认。冷色月光和薄雾略微抬亮外围地形，仍让中央灯塔保持最明亮的安全区；警报时南门照明会同步增强。

## 0.8.9 破城体专属造型

夜袭中的破城体换用独立的 Blender 模型，增加厚重的背甲、肩甲、护腿和前冲撞角，近处可见头部与胸口的炽热裂隙。四肢与头部仍由游戏内动作枢轴驱动，重型目标在坡道上更容易辨认。

## 0.8.10 回防寻路与重击

右键移动会绕开堡垒侧墙与坡道护栏，经南门回到灯塔；手动方向键可随时接管。破城体撞击增加蓄力下沉、重型前冲和短暂的碎石冲击圈。屏障技能改用 W，原先的前进键移到 Z（方向键 ↑ 仍可使用）。


## 0.8.11 黑夜与灯火

主角改用灰烬守望者模型：闭合头盔、分层旧钢护甲、琥珀胸灯与披风；髋、膝、脚踝分别驱动步态，并平滑切换行走与站立。完整夜间几乎没有全局照明，灯塔、提灯、南门哨灯、已建防御塔和已激活通信塔形成局部可见区。R 灯焰增加火纹、冲击圈、中心闪焰及短暂照明。新增振翅悬浮的噬灯蛾，靠近南门会压暗灯光，击杀后恢复；紫色小地图目标与提示帮助玩家识别威胁。
